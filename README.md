# Young Star Football Club (YSFC)

A responsive, single-page website for Young Star Football Club.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Before publishing

Update the sample content in `index.html`:
- Replace the placeholder fixture dates, opponents, venues, and kick-off times.
- Replace `PLAYER NAME`, positions, and shirt numbers with the official squad.
- Update the club's founding year and contact email (`ysfc@example.com`).
- Replace stock photography with the club's own photos and update the gallery.

The site is mobile-responsive and includes a collapsible mobile navigation menu.
